# data

## Purpose
Container directory for generated, committed game data. It holds no files of its own — all content
lives in `rules/`.

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `rules/` | Ten generated JSON rules catalogs, bundled at build time for offline use (see `rules/AGENTS.md`) |

## For AI Agents

### Working In This Directory
Nothing here is hand-authored. See `rules/AGENTS.md` before touching anything — the catalogs are
generated by `npm run rules:ingest` (`.dat`-derived JSON) and `npm run rules:extract`
(`modules.json`, from the desktop's C++ stage tables), and are lint-ignored.
